# Shervo Ticet

**Shervo Ticet** — Discord-бот для управления системой тикетов, разработанный на JavaScript с использованием [discord.js](https://discord.js.org/). Он помогает администраторам Discord-серверов организовывать обращения пользователей через приватные каналы поддержки.

## Возможности

- **Панель тикетов** — публикация интерактивной панели с кнопкой создания обращения.
- **Приватные тикеты** — создание отдельных каналов, доступных автору обращения и сотрудникам поддержки.
- **Лимиты тикетов** — настройка максимального количества тикетов в каждой категории.
- **Настройка названий категорий** — возможность изменять названия категорий тикетов.
- **Роль поддержки** — назначение роли с доступом к каналам обращений.
- **Перенос тикетов** — перенос существующих тикетов в новые категории с сохранением сообщений, встраиваемых элементов и вложений.
- **Закрытие тикетов** — закрытие обращений с помощью интерактивной кнопки.
- **Конфигурация в JSON** — хранение настроек бота в файле `config.json`.

## Требования

- [Node.js](https://nodejs.org/)
- Discord-приложение с созданным ботом.
- Токен бота и необходимые разрешения Discord.

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone <repository-url>
   cd <repository-folder>
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Укажите токен бота через переменную окружения `BOT_TOKEN`.

   **Windows PowerShell:**

   ```powershell
   $env:BOT_TOKEN="YOUR_BOT_TOKEN"
   ```

   **Linux:**

   ```bash
   export BOT_TOKEN="YOUR_BOT_TOKEN"
   ```

4. Запустите бота:

   ```bash
   node index.js
   ```

   Если главный файл проекта называется иначе, замените `index.js` на его имя.

## Команды

| Команда | Описание |
| --- | --- |
| `/panel` | Создать панель тикетов. |
| `/setlimit` | Установить лимит тикетов для категории. |
| `/setname` | Изменить название категории тикетов. |
| `/setrole` | Назначить роль сотрудников поддержки. |
| `/migratetickets` | Перенести тикеты из существующей категории. |

Для использования административных команд необходимы соответствующие права.

## Конфигурация

Настройки бота хранятся в `config.json` и включают:

- Максимальное количество тикетов на категорию.
- Название категории.
- Префикс каналов тикетов.
- ID роли поддержки.
- Счётчик тикетов.

## Важная информация

- При переносе обрабатывается не более 100 сообщений из каждого исходного канала.
- После переноса исходные каналы тикетов и их категория удаляются. Перед использованием функции рекомендуется создать резервную копию важных данных.
- Перед запуском на публичном сервере проверьте права доступа и настройки закрытия тикетов.
- Никогда не публикуйте токен бота в открытом репозитории.
